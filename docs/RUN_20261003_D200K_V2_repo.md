## 4. 运行中实际遇到的问题总表

### 4.1 端口 29500 被占用
- 现象：smoke 初次启动时，日志出现 `Address already in use`，默认 `29500` 无法绑定。
- 影响：8-GPU launcher 无法进入真正训练阶段。
- 处理：改为动态 `main_process_port`。
- 当前状态：**已修复**。

### 4.2 `AF_UNIX path too long`
- 现象：smoke 第一段在 Python multiprocessing / torch storage FD 共享阶段反复报：`OSError: AF_UNIX path too long`。
- 根因：`TMPDIR=$RUN_ROOT/runtime/tmp` 的绝对路径太长，超过 AF_UNIX socket 路径上限。
- 处理：
  - 在 `scripts/setup/common.sh` 中新增短 TMPDIR 逻辑；
  - 失败输出目录归档为：`$RUN_ROOT/outputs/cluster-smoke-20.afunix-failed-20261006T061034Z`；
  - 重新启动 smoke。
- 当前状态：**已修复**。

### 4.3 smoke verifier FAIL（当前唯一直接门禁阻塞）
- 现象：AF_UNIX 修复后，smoke 三段均已完成：
  - `cluster-smoke-20`
  - `fixed200k-smoke-resume-fresh10`
  - `fixed200k-smoke-resume-to20`
- 但最终 `outputs/fixed200k-smoke-verification.json` 为：

```json
{
  "error": "SmokeMismatch: training metrics[0].grad_norm_post_clip: values differ",
  "schema": "fixed200k-smoke-verification-v2",
  "status": "FAIL"
}
```

- 已确认现象：
  - `committed_sample_uids` 匹配；
  - `committed_geometry_seeds` 匹配；
  - `committed_corruption_seeds` 匹配；
  - `sample_mean_ce` 在 step 1 一致，均为 `4.235133647918701`；
  - 首批不一致字段集中在梯度诊断侧：
    - `grad_norm_pre_clip`
    - `grad_norm_post_clip`
    - `lora_grad_diagnostic`
    - `mask_embedding_grad_norm`

- step 1 对比：
  - uninterrupted `cluster-smoke-20`：`grad_norm_pre_clip = grad_norm_post_clip = 0.7455371193509229`
  - split `fixed200k-smoke-resume-fresh10`：`grad_norm_pre_clip = grad_norm_post_clip = 0.7454602824724359`

- 当前判断：
  - 问题不是样本顺序/cursor 的首要失败；
  - 更像是 backward / gradient-side exactness 没有满足 strict smoke verifier；
  - 仍需继续修复训练侧 exact determinism，而不是放宽 verifier。

- 当前状态：**未修复**。
